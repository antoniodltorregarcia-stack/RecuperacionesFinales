Apartado A


1. Clonar proyecto original y crear tu repo sin historia

- Clonar el repositorio del examen:

$ git clone git@github.com:andresalcarazrey/endes_abril_2026_devops.git

- Entramos a la carpeta

$ cd endes_abril_2026_devops/

- Eliminamos la carpeta .git 

$ rm -rf .git

- Creamos el repo en github (chrome)

...

- Iniciamos el git y lo enlazamos al repo

git init
git add .
git commit -m "Proyecto inicial sin historial"
git branch -M main
git remote add origin git@github.com:TU_USUARIO/endes_abril_2026_devops_antonio.git
git push -u origin main

2. Añadir dependencias GSon y JUnit Jupiter

- Buscamos la dependencia de Junit y la modificamos con lo que nos pida el enunciado

<dependency>
    <groupId>org.junit.jupiter</groupId>
    <artifactId>junit-jupiter</artifactId>
    <version>5.6.0</version>
    <scope>test</scope>
</dependency>

- En este caso el Gson estan igual no cambiamos nada

<dependency>
      <groupId>com.google.code.gson</groupId>
      <artifactId>gson</artifactId>
      <version>2.13.2</version>
</dependency>

3. Compilar y empaquetar con Maven

- volvemos al terminal y ejecutamos...

mvn clean package (nos debe salir una pila cosas)

/*
clean: Borra la carpeta target.

package: Compila, ejecuta tests y genera el artefacto (.jar o .war) en target/.
*/

4. Subir cambios a tu repositorio remoto

git status
git add pom.xml
git add .   # si hay más cambios
git commit -m "Añadidas dependencias GSon y JUnit Jupiter, compilado con Maven"
git push
